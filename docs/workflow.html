Building a world

The order that avoids backtracking, and the ten decisions that separate a scene that works from a scene that ships. Both art styles do all of this. What changes between them is two pages: stylized and realistic.

1. Texel density

Decide it once, write it down, and never argue about a UVScale again. Density is texture resolution divided by tile size in metres.

Seen fromDensity2K map tiles every
hands on it - hero props, doors, weapons1024 px/m2 m
walking past - walls, floors, rocks512 px/m4 m
terrain and anything above head height256 px/m8 m
distant cliffs, backdrop geometry128 px/m16 m

Then the two knobs that set it:

TriplanarScaleworld units per UV. 1 ÷ tile size in cm. A 2 m tile is 0.005; a 4 m tile is 0.0025
<Layer>_UVScale (landscape)tiles per landscape quad, not per metre. Never set it by hand - Mat → Fit UV Scale To Landscape… reads the landscape's own quad size and writes every layer at once
A resized landscape does not have the quads the defaults assume. Skip the fit step and every layer tiles wrongly at the same time, which reads as blur or moire rather than as a wrong number.

2. The layer plan

Write the layer list before generating anything. A base plus three to five painted layers covers most biomes; past four, turn on Texture Array Layers so eight layers is three texture objects instead of twenty-four.

  • Layer 0 is the base and holds whatever weight the painted layers leave behind. Make it the material the ground mostly is.
  • Name a layer Rock if you want slope rock - it overlays that layer where the ground gets steep, with nothing painted.
  • Name a layer Moss to paint moss on top of the four signals that place it automatically.
  • Name a layer Wetness to paint permanently damp ground.
  • Each layer also carries its physical surface and grass type, so paint decides what a footstep sounds like and what grows there.

3. Albedo and value

Nothing is baked in. No lighting, no ambient occlusion, no contact shadow. Every dark pixel you author is a dark pixel at noon.

ChannelKeep itWhy
base coloursRGB 30-240below 30 nothing bounces, above 240 nothing shades. Charcoal is 50, fresh snow is 235
cavity (CRM red)baked, like AOsame bake, different purpose: tight creases and edge curvature, not broad occlusion. It multiplies base colour and specular, and it is the only micro shadowing there is
roughness (CRM green)never 0, never 10 mirrors the sky, 1 kills the light. Author the variation, not the extremes
metallic (CRM blue)0 or 1nothing in the world is 40% metal. If your pack has occlusion in blue, set MetallicScale to 0
AOdo not author itthe renderer supplies its own. A baked AO map on top darkens twice

4. Blend by height

BlendHeightAmount at 0 is a plain cross-fade, at 1 is a pure interlock where the layers meet along their own detail: mortar filling before brick, gravel settling between cobbles. BlendContrast is how wide a band that happens over.

BlendHeightAmountBlendContrast
Surface, subtle0.450.5
Surface, deliberate0.80.7
Landscape default0.350.5

Contrast only widens the interlock band. It never softens the interlock itself, so a crunchy edge is fixed by raising contrast, not by lowering the amount.

5. Repetition, at three distances

Three different things give a tiled surface away, and each needs its own fix. Turn all three on.

DistanceWhat gives it awayFix
0-5 mthe texture runs out of detailbDetail, a fine normal, DetailScale 8, DetailStrength 0.5
5-40 mthe tile grid appearsmeshes: Layer0_TileBreak. Terrain: <Layer>_DualScale (on by default) or <Layer>_HexTiling for the layer that repeats worst
40 m +a large area reads as one flat tonebMacroVariation with a real low-frequency noise, Variation_NoiseScale 0.002

Which tier, and how to tune each one, is on Techniques.

Hex tiling is three rotated taps and costs three times the samples. Put it on the one or two layers that cover the most screen - grass, dirt - and leave the rest on dual scale, which is a second tiling overlaid for one extra tap.
Hex tiling averages three taps, which averages the variance away and washes the layer out. Raise VarianceRestore and set MeanColor to the texture's actual average, or it will look faded next to everything else.

6. Ground everything

A rock sitting on terrain cuts a hard silhouette into it. The fix is that the rock reads the terrain's own runtime virtual texture and fades into it, so repainting the ground moves everything standing in it.

  1. Tick Build Project Outputs on the landscape recipe and set the four paths beneath it. Generate.
  2. Mat → Wire Landscape Runtime Virtual Textures.
  3. Add the generated MF_<AssetName>RVTBlend to the mesh's own material.
bUseRVT on with nothing writing the texture reads zero: base colour 0 and roughness 0, so the terrain is black and mirror-smooth whatever the layers say. If you are not using virtual textures, turn bUseRVT off.

7. Vary per instance

Two props with the same material should not be the same colour. Neither should need a second material instance - every one of those is another shader map, multiplied by every vertex factory that wears it.

bColorVariationa hash of where the object stands. Free, automatic, no per-actor setup. Variation_HueRange 8°, Variation_SaturationRange 0.1, Variation_ValueRange 0.1
bMacroVariationworld-space noise, so it varies across one mesh as well as between them. The only source that breaks up a single long wall
bPrimitiveDatatint, roughness and wetness per actor from custom primitive data, when a specific object needs a specific value. Set Num Custom Data Floats on the component

8. Weather is a world value

Turn on bWetness on whatever should respond, then drive one number on the weather collection. Mat → Open MPC_MobWeather and drag Wetness 0 to 1, live in the viewport.

Same for Snow: it settles across the world by which way each surface faces, crevices first and flats last, on terrain, props and roofs together, and it costs no texture sample. Point several recipes at one collection and a whole project follows it.

9. Judge in the debug views

Turn on bDebug and set DebugMode. Output goes to emissive with base colour blacked out, so what you see is only the thing you asked about. This is the part that saves the most time.

Layer Weightswhich layer is actually winning where. Check this before touching a blend number
Heightwhat the interlock is resolving against
Cavitywhether the micro shadowing is doing anything
Vertex Colourwhat you actually painted, remembering black adds
Wetness, Accumulation, Tramplethe weather masks on their own
Normal, Transmissionsurface direction, and light through a leaf

10. What it costs

Measured from the generated HLSL for the surface master. Samplers stay at 4 in every permutation.

Texture tapsPS instructions
Everything off3999
One extra layer61082
One triplanar layer91051
Three layers, all triplanar271289

The number to watch is not instructions, it is permutations. Every distinct set of static switches is a shader map, and PSOs are per vertex factory times material. Parent to a preset, reuse presets across assets, and run Mat → Report Cost before shipping. Detail on Cost.

Checklist

  • One texel density, written down, and Fit UV Scale run on every landscape.
  • No AO anywhere. Cavity is doing that job.
  • Every blend has BlendHeightAmount above 0.
  • Detail, tiling break and macro variation all on, with real art in DetailNormal and MacroNoiseTexture.
  • Nothing meets the ground with a hard silhouette.
  • No two adjacent copies of a prop are the same colour.
  • Wetness and Snow both move the whole scene from one collection.
  • Preview platform is ES3.1, and the scene was judged there.
  • Verify Contract passes and Report Cost is a number you are happy with.
