MobMaterials

Landscape, surface and foliage master materials for Unreal's mobile forward renderer. Built for stylized and realistic projects alike.

cd YourProject/Plugins
git clone git@github.com:Vaei/MobMaterials.git

Install it →

Not officially released. Expect bugs and updates without versioning. Documentation is still filling in.

What you get

LandscapePaint layers that interlock along their own height, stochastic hex tiling that kills repetition at any distance, slope rock and moss placed by the terrain itself, and the whole blend cached into a runtime virtual texture so a dozen layers cost what one does.
SurfaceThree layers, vertex paint, triplanar, parallax, detail normals, distance tiling break, per-instance variation and weather. Every feature gated by a static switch, so what you turn off is not compiled.
FoliageMasked, two-sided, light through the leaf per texel, two scales of wind, and grass that gets pushed aside by what runs through it.

Twenty minutes to a world

  1. Enable the plugin, set four project settings, generate a master from a recipe.
  2. Put an instance on a mesh and set three textures.
  3. Generate a landscape master, paint it.
  4. Drag Wetness from 0 to 1 and watch the whole world respond.
